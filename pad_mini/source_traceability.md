## Candidate-only sources (not implemented as decisions)

- CHROM: de Haan & Jeanne, TBME 2013, DOI `10.1109/TBME.2013.2266196`.
- POS: Wang et al., TBME 2017, DOI `10.1109/TBME.2016.2609282`.
- LBP microtexture: Määttä et al., IJCB 2011, DOI `10.1109/IJCB.2011.6117510`; classifier excluded.
- Color texture: Boulkenafet et al., TIFS 2016, DOI `10.1109/TIFS.2016.2555286`; LBP/SVM excluded.
- Chromaticity map motivation: Chen et al., CVPR 2024, pp. 15577–15586; transformer adapter excluded.
- Edge profiles: Thongkamwitoon et al., TIFS 2015, DOI `10.1109/TIFS.2015.2392566`; K-SVD/SVM excluded.
- PRNU: Lukáš, Fridrich & Goljan, TIFS 2006; not implementable as source matcher without trusted reference images.
- Resampling: Popescu & Farid, IEEE TSP 2005; not yet runtime-enabled.

## Project dependency licenses

The repository depends on NumPy (BSD-3-Clause), OpenCV Python packages (Apache-2.0 for current OpenCV), optional PyWavelets (MIT), Pillow (HPND), and MediaPipe infrastructure (Apache-2.0). Deployment must retain the corresponding notices and verify the exact wheel/source licenses in the release SBOM. None of these dependencies supplies a trained PAD decision in the deterministic path.
